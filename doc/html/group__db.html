STATUS ExDbGetNextBool ( struct ExDbHandle *  h,
const char *  name,
bool *  b 
)

Get (next) boolean with given name from database.

Parameters
*hDatabase handle
*nameEntry name
*bOutput boolean
Returns
Status code. If different than OK, then b is invalid.
Note
This function can be called multiple times, e. g., to obtain multiple entries from an array. If the end of array or database is reached, this function fails, the internal state is cleared and at the next call the search starts from the beginning. Use ExDbRewind() to clear internal state manually.
