◆ IoFileOpenMode

enum IoFileOpenMode

File open modes.

File content is available for reading in IO_FILE_READ, IO_FILE_WRITE and IO_FILE_APPEND modes. IO_FILE_WRITE allows to write to any offset without destroying current file content (except the content being explicitly overwritten). IO_FILE_APPEND allows to append content to the end and ignores provided offset. IO_FILE_REPLACE flag can be ORed with open mode to destroy current file content. IO_FILE_READ_ATTRIBUTES allows to read file attributes via IoFileAttributes structure. IO_FILE_WRITE_ATTRIBUTES allows to write file attributes via IoFileAttributes structure. By default, when the file does not exist, the function fails and nothing is read nor written. IO_FILE_CREATE flag ORed with open mode allows to create the file if it does not exist. Using IO_FILE_READ_ATTRIBUTES or IO_FILE_WRITE_ATTRIBUTES with IO_FILE_WRITE or IO_FILE_APPEND is illegal and result with open error.
