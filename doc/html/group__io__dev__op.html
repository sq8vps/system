Detailed Description

I/O operation helpers.

This small module provides generic helpers for typical I/O operations on devices.

Perfrom synchronous device read.

This function performs direct I/O read if possible in the first place. If offset alignment is not compliant with device block size and alignment requirements, then the double buffering is used. Otherwise a direct read is performed. The same restrictions apply when buffer is already provided by the caller.

Parameters
*devDevice object to perform the read on
offsetOffset to start reading from
sizeSize of data to read
**bufferOutput buffer pointer, allocated by this function
Returns
Status code
