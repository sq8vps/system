Detailed Description

Real mode emulator.

This module provides a x86 real mode emulator. The emulator can be used, e.g, by the graphic drivers to execute video BIOS interrupts. Please note, that this emulator allows only for real-mode (<1MiB) memory access and does not implement switching to protected mode.

Real mode stack top.
