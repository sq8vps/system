◆ HalRegisterVideoResetRoutine()

void HalRegisterVideoResetRoutine ( HalVideoResetRoutine  resetRoutine,
void *  context 
)

Register video driver reset routine.

The reset routine is used by the kernel to reset the video adapter to a known state, where it can be set up and used by the kernel video driver. The reset routine is invoked only on kernel panic to print the panic message without relying on the external video driver.

Parameters
*resetRoutinePointer to the reset routine
*contextContext pointer passed to the reset routine
