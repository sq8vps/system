◆ KeWakeUpTask()

void KeWakeUpTask ( struct KeTaskControlBlock *  tcb)

Notify and wake up task.

Notify sleeping task that tit should wake up. If the target task is blocked because of sleep, it will be unblocked. If the target task is block because of any other event, it will not be unblocked.

Parameters
*tcbTarget Task Control Block
