◆ KernelPanicCode

enum KernelPanicCode

Main kernel panic error codes.

Enumerator
KERNEL_MODE_FAULT 

An uncorrectable kernel mode fault occurred.

An uncorrectable kernel mode fault occured. Refer to architecture-specific error codes for details.

BOOT_FAILURE 

A critical error occured during early boot stage.

NO_EXECUTABLE_TASK 

No task to be executed is available.

This error should not normally occur.

UNACQUIRED_MUTEX_RELEASED 

A mutex-like object was released without being acquired first.

BUSY_MUTEX_ACQUIRED 

A mutex-like object was acquired before being released.

UNEXPECTED_FAULT 

A unknown fault occured.

DRIVER_FATAL_ERROR 

A fatal driver-defined error occured.

PRIORITY_LEVEL_TOO_LOW 

Current priority level is too low to execute the operation.

PRIORITY_LEVEL_TOO_HIGH 

Current priority level is too high to execute the operation.

RP_FINALIZED_OUT_OF_LINE 

A queued Request Packet was finalized out of line in a simple queue.

ILLEGAL_PRIORITY_LEVEL_CHANGE 

An illegal priority level change occured.

ILLEGAL_PRIORITY_LEVEL 

An illegal priority level was requested.

OBJECT_LOCK_UNAVAILABLE 

There was an attempt to lock the object that is not lockable.

MEMORY_ACCESS_VIOLATION 

There was an attempt to access illegal memory.

INVALID_TASK_ATTACHMENT_ATTEMPT 

A task attachment request was invalid.

  • Arg 0: Error type:
    • 0 - source and target tasks are the same
    • 1 - source task is already attached to some task
    • 2 - source task is not a kernel mode thread
  • Arg 1: Source task control block (attachee)
  • Arg 2: Target task control block
  • Arg 3: Task to which the source task is currently attached (for error type 1 only)
