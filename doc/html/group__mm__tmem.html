Detailed Description

This module provides routines and data structures for per-process memory management.

enum MmTaskMemoryFlags

Flags for MmTaskMemory descriptor.

Enumerator
MM_TASK_MEMORY_READABLE 

Region is readable

MM_TASK_MEMORY_WRITABLE 

Region is writable

MM_TASK_MEMORY_EXECUTABLE 

Region is executable

MM_TASK_MEMORY_SHARED 

Region is shared, write directly to underyling buffer

MM_TASK_MEMORY_WRITE_THROUGH 

Write directly to mapped file rather than to a private buffer

MM_TASK_MEMORY_REVERSED 

Region grows down - the top pointer is returned and the top pointer is expected when mapping and unmapping. This flag is illegal for file mappings.

MM_TASK_MEMORY_GROWABLE 

Region can grow beyond its original size - downwards if MM_TASK_MEMORY_REVERSED is set

MM_TASK_MEMORY_LOCKED 

Region is a fundamental process memory which can't be removed

MM_TASK_MEMORY_FIXED 

Map memory exactly to given address, fail if not possible. Fixed allocations do not have guard pages unless they are growable.

MM_TASK_MEMORY_STACK 

A set of flags for allocating stacks

)

Map task memory.

Parameters
*addressAddress to map to. If NULL, the kernel selects a suitable page-aligned address. If not NULL, the kernel might take a hint about where to place the mapping. If MM_TASK_MEMORY_FIXED flag is specified, then mapping is placed exactly at the specified address. If it's not possible (bad alignment, region already mapped, etc.) the function fails. If MM_TASK_MEMORY_REVERSED flag is specified, the address must point to the top (highest) address of the mapping.
sizeSize of the mapping. The actual mapping size is rounded up to the page size. If fd (file descriptor) is provided, then size specified the number of bytes to read starting at offset from the file.
flagsMapping flags. Refer to MmTaskMemoryFlags
fdDescriptor of the file to be mapped. If negative (<0), a zero-initialized memory mapping, not backed by any file, is created. File open mode must not conflict with provided flags.
alignmentRequired alignment. Memory is always at least page aliged.
offsetOffset within the file, must be page aligned. If file is not provided, then it is ignored.
limitRegion size limit if MM_TASK_MEMORY_GROWABLE flag is specified. The limit does not include the guard page size.
**mappedMapped region pointer. If MM_TASK_MEMORY_REVERSED flag is specified, the pointer referes to the top (highest) address of the mapping. If the returned status is not OK, the value is invalid. NULL can be provided if this pointer is not needed.
Returns
Status code
