Detailed Description

Local APIC support module.

Warning
This is for internal use only

This module provides support for LAPIC. This includes handling processor priorities, system timer, IPIs (low-level), and sending EOIs. While the LAPIC timer can be used as a time source, kernel mode drivers should use HAL to obtain timestamps.
